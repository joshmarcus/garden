# Context garden

This repository contains the goals, specifications and task state for `joshmarcus/context-garden`; the product code lives in separate worktrees.

Read `AGENTS.md` for the single current operator handoff and `.claude/skills/garden-operate/SKILL.md` for procedures. Do not start a server, dispatch work or change configuration before reading the current handoff. It includes maintenance state, resource limits, active PR work and the installed pin.

Task state is scheduler-owned; use supported CLI or web actions. Historical operator notes are archived under `context-garden/docs/operator-history/` and are not an active queue.
