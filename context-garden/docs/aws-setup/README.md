# AWS setup package

Prepared under owner authorization; not deployed. `infrastructure.template.json` defines tagged networking, HTTPS egress-only security group, ContextGardenWorker role/profile and one retained bootstrap secret. It creates no instance and does not change ContextGardenProvisioner. The subnet has an internet route/public IPv4 for outbound access to avoid an hourly NAT gateway; the security group admits no inbound traffic. Tailscale keeps access to Babel private.

Use a non-root infrastructure-administrator AWS profile. The existing garden-provisioner role returned AccessDenied for iam:GetRole and cannot create these IAM/network resources. Do not use the root default profile or widen the provisioner automatically. Validate the template and create a CloudFormation change set with CAPABILITY_NAMED_IAM; inspect existing named role/profile/secret collisions before execution. Do not execute against a different account or region. Account350111791226, us-east-1, stack context-garden-phase05-infrastructure.

The template's secret is retained on stack deletion to prevent accidental loss; explicitly inventory and retire it after the experiment if no longer needed. An administrator must populate it through a secure file/console, never chat or user data, after tailnet policy verification. Use short-lived, single-use ephemeral Tailscale enrollment for the one-host canary. Review the existing ACL: merely adding a narrow grant does not restrict a pre-existing wildcard allow. Permit this worker identity to reach Babel HTTPS only while preserving owner device access. Do not enable Funnel or public inbound SSH.
