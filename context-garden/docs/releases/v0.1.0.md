# v0.1.0 — initial deployed preview

This release names the existing deployed build; publishing it does not upgrade the running garden or establish phase-05 completion. It is marked prerelease because stabilization remains in progress. Package version is 0.1.0.

## Source and validation

- Exact commit: 899b2c0cda5a311f6e498b75929ca6b58a524eab.
- Exact main CI: https://github.com/joshmarcus/context-garden/actions/runs/34112718574 (passed).
- Deployment on 2026-09-07 used a drained scheduler boundary and a bounded installer; 38 focused resource/restart/setup checks passed before rollout.
- Initial Now/Inbox/Config smoke checks passed. These do not prove unattended stability.

## Included

The existing garden CLI/web scheduler, worker/review loop, resource-isolation corrections, Inbox history-read optimization, incident controls, worker accounting, and earlier fence/artifact recovery fixes.

## Known limitations and exclusions

- Cache-heavy cgroup accounting can conservatively withhold admission despite host memory availability; investigation remains active.
- Human-action Inbox classification and review churn improvements remain in progress.
- Four-hour productive unattended operation and complete recovery journeys are not established by this release.
- Later merged conflict-prompt recovery (PR283), maintenance pause (PR288), walkthrough renderer (PR277), and remaining hand-merge fixes (PR255) are not in this build.
- Managed AWS workers are not available in this release. No cloud resources are provisioned by installing it.

## Install and rollback

Source installation can reference tag v0.1.0; operators should resolve and verify the exact commit above. Follow the garden's safe deployment protocol and preserve run state and artifacts. Keep the previously deployed source pin available for rollback; rollback does not rewind task state or erase evidence. This first release provides source archives, not PyPI publication or prebuilt wheels.
