# user review of context-garden/phase-04

**Persona:** user · **Score:** 7/10 · 2026-09-05T22:42:52+00:00

Phase 04 makes the loop leaveable in the ways I care about: live config reload with the restart keys named, one profile switch for how hard the garden runs, a costs page that matches the CLI, and an approve card that names the gap in a brief. But the new brief gate is undone by the Dispatch now button and the new-task form's approve-now path, Mark done still sets done without a merge, and the built-in profile stops are Claude-only, so I would not yet leave it overnight with automerge on for a codex garden or a phase with fresh drafts.

## High

- **brief gate** — Dispatch now on a draft and the New task form's approve-now both skip the approve gate, so a task with placeholder criteria dispatches a run.
  - suggestion: Route the dispatch web action for a draft and the form's ready status through Scheduler.approve (brief_gaps), and hide Dispatch now on a draft whose card shows a gap; close garden take the same way.
- **Mark done** — The Mark done button on every in-review card sets status to done directly in the web action, bypassing _transition and the done-means-on-base rule from CG-228.
  - suggestion: Send it through a shared Scheduler.mark_done that uses _transition, label it as an escape hatch (e.g. 'Mark done without merging') with a confirm, and drop it from the review card's primary row.

## Medium

- **operating profiles** — The built-in economy, balanced and fast stops hardcode Claude model ids and model_for applies a stop's tier map to any harness, so a codex garden switching stops gets Claude model names.
  - suggestion: Key a stop's models per harness (or by the harness's own tier map) and only apply a stop's models to a harness it names; say so in the rail meaning line.
- **fixing a brief** — The approve card says to fix the brief but the task page offers no way to edit criteria or the reading list; the only in-app path costs an edit run.
  - suggestion: Add an inline edit form for a draft's acceptance criteria and reading list on the task page, validated by the same brief_gaps check.

## Low

- **Config page** — tick_interval appears both under live re-read values and under the needs-a-restart list.
  - suggestion: Show each key in one list only; put tick_interval under restart.
- **observe and costs copy** — The Costs page files a resume round as 'other', and garden observe's digest reported one failed run on a QA garden whose event log has no failed transition.
  - suggestion: Give resume its own activity name and make the digest's failed count read the same terminal statuses the Board does.
- **garden status** — With every phase closed, garden status prints an empty table and its legend before the closed-phase note.
  - suggestion: Skip the table and legend when there are no open phases and lead with the closed-phase line.
